# Ozioma.dev - Professional Portfolio

A modern, responsive portfolio website showcasing full-stack projects, skills, and professional experience. Built with React, Vite, and modern web technologies.

## 🚀 Features

- **Project Showcase**: Detailed case studies with architecture breakdowns, technologies, and live demos
- **Responsive Design**: Optimized for mobile, tablet, and desktop experiences
- **Performance Optimized**: Built with Vite for fast development and production builds
- **Modern UI/UX**: Clean, accessible design with smooth animations
- **Multiple Project Categories**: Full Stack, WebApps, E-commerce, UI/UX, SaaS, and Tooling

## 🛠️ Tech Stack

### Frontend
- **React 18** - UI library
- **Vite** - Build tool and dev server
- **Tailwind CSS** - Utility-first styling
- **Framer Motion** - Animations and transitions
- **React Icons** - Icon library

### Development
- **Node.js** - Runtime environment
- **ESLint** - Code linting
- **Modern JavaScript (ES6+)** - Latest language features

## 📁 Project Structure

```
src/
├── components/
│   ├── layout/          # Header, Footer components
│   ├── sections/        # Page sections (Hero, About, Skills, Projects, Contact)

```

## 🚀 Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn package manager

### Installation

1. Clone the repository
```bash
git clone https://github.com/ozi-Shalom2333/portfolio.git
cd portfolio
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:5173`
